# Cupcake Day

A pastel cupcake decorator for Crystal. Soft pinks, lavender, mint, and peach, with sparkles and cute toppings. Pure static HTML, CSS, and JS. No build step, no framework.

## Open it

- Double-click `index.html`, or open it in any browser.
- Or serve the folder:

```bash
cd cupcake-day-ship
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Or:

```bash
npx serve .
```

## Controls

1. Tap a topping on the tray (sprinkles, cherry, star, heart, candy pearl, bow).
2. Tap the cupcake frosting to place it. Sparkles pop on place.
3. Soft toasts like "Yum!" appear after a few toppings.
4. **New cupcake** clears toppings and starts fresh.
5. **Surprise me!** drops a handful of random toppings.

Works with mouse and touch.
